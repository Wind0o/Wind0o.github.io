隐私政策

更新日期：2026 年 9 月 21 日

FileFly 是本地文件浏览、传输与备份工具。我们不要求注册账户，不包含广告、追踪或第三方分析 SDK，也不运营用于接收或中转你的文件的服务器。

你通过系统文件选择器授予目录访问权限。目录书签和应用设置保存在设备本地。FileFly 仅访问自身文件及你授权的目录，无法自动批准其他位置的访问。配对密钥仅在应用运行期间保留在内存中。

共享功能将文件和必要的目录信息加密传输到你配对的 Mac。Mac 保存你选定的文件副本，以及包含相对路径、字节数、SHA-256 校验值、时间和完成状态的备份清单。读取期间会生成临时副本；正常完成或取消会清理临时文件，异常退出可能留下由系统或后续维护清理的缓存。

停止共享、移除目录或卸载移动端应用不会删除已经保存到 Mac 的副本。你可在保存位置自行删除文件与清单；移除授权或卸载应用可清除其本地访问配置。

云端文件可能由 Apple 或其他文件提供方下载至设备。这些服务受其各自隐私政策约束。若你主动联系支持，所发送的联系方式、问题描述和附件会用于处理你的请求；不要发送配对密钥或不必要的私人文件。

FileFly 不将文件用于分析、广告或模型训练。若实际数据处理发生变化，我们将更新本政策和商店隐私披露。

使用支持

联系方式：01057@163.com。

找不到设备：在两端允许本地网络访问，连接同一 Wi-Fi，并让移动端 FileFly 保持前台共享。不要使用公共或不可信的配对密钥。

USB：仅独立分发的 Mac 桌面版提供 USB；Mac App Store 版通过 Wi-Fi 连接。USB 设备需要解锁并信任 Mac。

授权范围：一次选择一个或多个目录，即包含其全部子目录。未授权位置、系统目录和其他应用的私有数据不在访问范围内。

备份中断：已完成文件与清单保留，清单会标记未完成。保持移动端前台共享后，重新选择新备份目录重试。当前版本不支持断点续传。

文件无法读取：先在系统“文件”App 打开该文件以确认下载与权限；检查两端存储空间。FileFly 是文件副本备份工具，不是整机备份工具。

Privacy & support

FileFly browses user-authorized folders and transfers files to the user's paired Mac over an encrypted local connection. No FileFly account, advertising, tracking SDK or developer-operated file server is used. Folder permissions and settings stay on-device. Pairing keys are kept in memory.

Downloads and backups are saved at the user's selected Mac destination. Backup manifests contain relative paths, sizes, checksums and completion details. Revoking mobile access does not remove downloaded copies. Cloud file providers operate under their own privacy policies. Information voluntarily sent to support is used to handle that request.

The Mac App Store edition uses local Wi-Fi. USB is available only in the independently distributed desktop edition. Keep the mobile app in the foreground while sharing. This is a file-copy backup utility, not a full device-backup or sync service.
