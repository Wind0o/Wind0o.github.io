## 1. 热榜原小说真正的结构（不是「竖屏可拍」四个字）

番茄爆款被红果拿去拍，靠的是下面这条生产线，不是权谋说明书。

### 1.1 书名 = 卖点整句

- 《发配边关，罪妻开荒养出战神》：场景+身份+金手指+结果
- 《都重生了，谁还装富二代啊》：态度反转
- 《她竟然不干了》：拒绝原著

反例（上一版）：《退婚当天，女战神带铁骑来喝喜酒》——卖点只在开场，后面变成钥匙/粮契/伪诏，书名承诺的「喝喜酒」在第2章就结束。

### 1.2 章标题 = 钩子，不是「第一章 退婚喜堂」这种空壳

《都重生了》目录实证：

- 第1章 被拆穿的富二代
- 第3章 先找个愿意回去的地方
- 第24章 碾压的交割单与京城来的背景
- 第63章 停车场的围观与即将掀翻全校的误会

《发配边关》目录实证：

- 第001章 罪奴发配现场
- 第002章 挑选媳妇
- 第007章 木系异变
- 第008章 大丰收
- 第013章 新媳妇对比

规则：**一章只办一件事；章名能当短视频标题。**

### 1.3 一句话主线（投稿生死线，官方第04课）

> 主角 + 目标 + 阻碍 + 亮点

- 《发配边关》：罪妻苏禾 + 活下去并养家 + 粮荒/战火/极品邻居 + 木系开荒
- 《都重生了》：陆川 + 不装富二代、认真生活 + 误会流把安静过成高调 + 重生先知
- 《她竟然不干了》：苏棠 + 跑路不当炮灰 + 赐婚/白月光剧本 + 金融脑子
- 《替君语落阶》：沈明珠 + 改炮灰命运 + 渣男假千金 + 吃瓜系统

反例（上一版）：女帅回京 + 打脸 + 隐婚瘸子 + 双子被劫 + 四把钥匙 + 粮契 + 细作玉。目标超过一个，写到中段只能硬编权谋。

### 1.4 章内闭环（原小说）≠ 分镜卡点（剧本）

原小说一章大约 1500–2500 字，结构是：

```
开场事件（对白/冲突，不写天气）
  → 主角用金手指或态度做一个选择
  → 当场兑现一小口爽（打脸/收获/关系变化）
  → 对照组（邻居/女主/前世）对照一次
  → 章末只留一个新问题
```

《她竟然不干了》第一章实证：

1. 对白开场：「我是个假千金？」
2. 三秒决定：跑
3. 当场行动：翻箱倒柜、资产配置
4. 对照组：原著「郁郁而终」四个字
5. 章末钩子：今晚走，角门婆子已灌酒

《发配边关》前十五章实证：发配→挑选→穷日子→金手指→丰收→药材→对照组较劲。每一章都能单独讲完，升级是台阶不是迷宫。

### 1.5 对照组，不是第四把钥匙

爆款用「旁边那户」把爽感可视化：

- 开荒文：沈家新媳妇 vs 苏禾
- 团宠文：被低估的小师妹 vs 外人嘲讽
- 不干了文：还在按剧本演的女主 vs 跑路的炮灰

对照组每几章对照一次，比埋四把钥匙更像结构。

## 2. 公开爆剧剧本真正的结构

### 2.1 工业格式（凉白开 / 白羊，可直接套）

```
第x集
【人设一句话】
【转折一句话】
【卡点一句话】

1-1  日 内  地点
人物：A  B

△动作（可拍）
A（语气）：台词≤20字
B：台词

1-2  …
```

要素：场号、日夜内外、地点、人物表、△/▲动作、对白、OS/VO少用、字幕、卡点。燕北铁律：能对白就不画外音，能表演就不用独白。

单集 500–800 字，对应 1–3 分钟。全剧 80–100 集。核心角色 3–5 人，总共不超过 20 人。

### 2.2 黄金开场 = 一集写清「身份 + 困境 + 目标」

《丹帝转世》公开开场时间轴：

| 秒 | 发生什么 |
|---|---|
| 0–20 | 爷爷暴怒训斥「非礼城主千金未遂」——冲突画面，不介绍世界观 |
| 20–90 | 闪回炼鼎爆炸——身份：丹皇穿越 |
| 90–120 | 「堂堂丹皇，竟然穿成一个废物」+ 小翠闯门「城主来抓人」——困境升级 |
| 120–140 | 城主轰碎大门——卡在高潮前一秒 |

《诛仙台》公开第一集：

- 起：诛仙台行刑 + 话痨被贬（反差人设）
- 承：天将喊出主线任务「扭转尚书府命运才能回天庭」
- 转：闪回全家被害；马车里女主 OS vs 三哥听心声
- 合：卡在「要我们全家的命？」——不闭环

官方第03课原话：平台最先看的是 **1-1 第一集第一场**。平淡 = 待定/淘汰。前 30 秒定生死。

### 2.3 主线阶段（官方第04–05课）

| 集数 | 必须完成 |
|---|---|
| 1–10 | 立主线、亮核心看点。前三集给兴趣+情绪+悬念 |
| 11–30 | 主线实质性推进，冲突后必须有缓冲日常 |
| 31–80 | 伏笔揭晓、多轮反转、目标达成 |

复仇/逆袭节奏：**三五集一个小高潮，十集一个大高潮。**

情绪点（第07课）：**每集 1 个小情绪点；每 5–10 集 1 个大情绪点。**《开局女帝做正宫》第1–4集蓄力，第5集当众展露强者，兑现前4集伏笔。

### 2.4 钩子：把高潮切开，一半留到下一集

官方第06课原话：「人是会为冲动付费的，但不会为已经得到的东西付费。」

有效：未说完的质问、门推开一半、姐姐下车「你们找死」（《八个姐姐》一卡）。
无效：主角内心复述目标；一集内把起承转合写完。

大期待最晚第2集必须直白说出来，不要藏。

### 2.5 改编不是把小说切成竖屏

官方第10课 + 《冒姓琅琊》实践：

- 保留约 60% 内核，改节奏
- 《被赶出侯府》把原著长铺垫压成 3 分钟三次身份反转
- 反面：穿越后一碗粥 + 温吞日常 = 短剧致命
- 反面：燕北《都市神王夫妇》按小说节奏写成 167 集，市场中下

## 3. 上一版为什么「没结构」

对照上表，上一版同时踩了官方点名的坏稿行为：

1. **主线超过一个。** 打脸、隐婚、救子、钥匙、粮契、细作，写到中段只能硬编。
2. **章不是章。** 700 字一章，像分镜，不像番茄正文；章名空，没有「一章一事」。
3. **没有金手指兑现循环。** 能力在开场一次用完，后面靠权谋填。
4. **没有对照组。** 爽感无法可视化。
5. **大期待藏在权谋里。** 官方要求第2集直说。
6. **把短剧铁律直接浇在小说上。** 小说要章内闭环；剧本才把高潮切开。两种章法混用，读者两边都不爽。

## 4. 本项目采用的结构（写进正文）

一句话主线：

> 客服主管顾晚宁穿成原著第3章被毒死的女配，绑定「天道售后」系统；每结一单炮灰工单就改掉一个虐点。她本想摸鱼下班，却发现救下的全是隐藏大佬，而原著女主要把剧情强行掰回去。

对标引擎（吃热、不抄情节）：

- 吃《她竟然不干了》的态度：三秒决定不按原著死
- 吃《发配边关》的章法：一章一事、金手指当场兑现、对照组
- 吃《听物成团宠》的循环：能力每章用一次，团宠是结果
- 吃《替君语落阶》的主线：改炮灰命运 + 系统
- 吃《诛仙台》《丹帝转世》的剧本开场：1集内身份+困境+目标，卡在高潮前

明确不写：退婚喜堂铁骑、四把钥匙、粮契伪诏、下跪扇巴掌流水线。
