# 第3集

【女主当众报修中门工伤；对照组把毒酒改成安神】
【转折：第二杯酒送到厢房；顾晚宁换成醋，绿火证据留下】
【卡点：燕迟只说一个字「验」；子时将至，六人绕路砸门】

3-1  夜 内  顾晚宁厢房
人物：顾晚宁、丫鬟、顾衡

△丫鬟跪着举盏，哭得比酒热。

丫鬟：小姐，夫人说这是安神的，真千金都喝过了。

顾晚宁：你喝一口。

丫鬟（脸白）：夫人吩咐，只能小姐喝——

顾晚宁（盖章「待查」）：那就是质检不合格。

△她把酒倒进洗脸盆，舀一勺醋兑进空盏，还给丫鬟。

顾晚宁：拿回去。就说晚宁谢夫人安神，已经喝了。味道很酸，安得很好。

3-2  夜 内  厢房
人物：侯夫人、沈皎月、燕迟、顾晚宁、顾衡

△侯夫人盯着洗脸盆。沈皎月跟在后面，眼里含泪。

侯夫人：你把府里的心意倒了？

顾晚宁：心意如果是杏仁，建议走太医。

沈皎月：母亲别气，这盆水我让人倒了就是——

△顾衡把洗脸盆端到风口。杏仁味散不掉。绿意在夜色里不真切，味是真的。

燕迟（皱眉，不看沈皎月）：验。

△沈皎月的白玉镯碰了一下盏沿，轻响。

顾晚宁：中门今晚有工伤风险。建议取消。

3-3  夜 外  厢房门外
人物：家丁X6、顾衡、顾晚宁

△子时将至。六个人绕过中门，直接砸厢房门。

△顾衡把顾晚宁推到床后，自己挡门。第一棍打在门板上。第二棍打在他肩上。第三棍，他抓住了。

顾晚宁：工单001-B，现场结案。

△账本翻开。顾衡回头。

（卡点）
△哑巴顾衡开口。嗓子像生锈的井。

顾衡：晚宁，这单——我帮你结。
