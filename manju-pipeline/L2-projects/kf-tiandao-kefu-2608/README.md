# kf-tiandao-kefu-2608

S 级红果漫剧向原创小说。本项目相对上一版《退婚当天，女战神带铁骑来喝喜酒》的改法：先读热榜原小说和官方公开爆剧剧本，再按它们的结构写，而不是用分镜说明书冒充网文。

## 作品

- **剧名**：《穿书后我成了天道客服》
- **长标题**：《穿成女配当天，炮灰把虐点投诉到我工位上》
- **正文**：`source/novel.md`（16 章完结，一章一事）
- **下载**：`downloads/穿书后我成了天道客服.txt`
- **题材包**：穿书不干了 × 系统工单 × 炮灰改命 × 对照组翻车
- **集数预估**：80 集
- **黄金三集**：`05_scripts/ep-001~003.script.md`（凉白开/白羊公开格式）

## 一句话主线

客服主管顾晚宁穿成原著第3章被毒死的女配，绑定天道售后；每结一单炮灰工单改掉一个虐点。她想摸鱼下班，救下的全是隐藏大佬，原著女主要把剧情掰回去。

## 结构来源（必读）

`manju-pipeline/L3-library/hit-structure-from-public-sources.md`

吃的引擎：

- 《她竟然不干了》：对白开场、三秒决定、不按原著死
- 《发配边关，罪妻开荒养出战神》：一章一事、章标题即钩子、金手指当场兑现、对照组
- 《替君语落阶》公开大纲：改炮灰命运 + 系统
- 《诛仙台》《丹帝转世》公开剧本：1 集内身份+困境+目标，卡在高潮前一秒

明确不写：退婚喜堂铁骑、四把钥匙、粮契伪诏、下跪扇巴掌流水线。

## 人设记忆点

- 女主顾晚宁：「这单我接了。」「差评已登记。」破账本盖章「结案」。
- 对照组沈皎月：开口「我能懂」；白玉镯槽里藏杏仁。
- 顾衡：哑巴开口第一句是工单。
